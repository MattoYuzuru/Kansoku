# TDD 20 — Opportunity evaluation lab

## Research-only boundary

No production schema, classifier or dashboard metric is authorized by this TDD. The session first
produces an approved threat model, rule schema, controlled sanitized corpus, review protocol and
formula proposal.

## Candidate contract

Eligibility evaluation accepts an ephemeral task representation and current exposed-skill snapshot.
Durable output is limited to evaluator/rule ID and version, skill identity, result, bounded reason
category, confidence, evidence lineage and timestamp. Inputs and reconstructive features are
forbidden.

Missed requires eligible=true, selected=false and complete exposure/invocation coverage. Activation
recall requires explicit numerator, denominator, exclusions, minimum sample and false-positive
estimate.

## Exit gate

Only after privacy, reproducibility and false-positive gates pass may a later implementation TDD
authorize production code. Until then Opportunity is omitted from the primary component UI.
