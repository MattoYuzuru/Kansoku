Kansoku — Third-party license attributions
===========================================

This file records third-party assets and libraries redistributed in the
Kansoku dashboard frontend (web/, embedded into the Go binary via
internal/webui). Runtime JS/TS npm dependencies (React, wouter, TanStack Query,
Apache ECharts, and their transitive deps) are declared in web/package.json and
carry their own licenses (MIT / Apache-2.0); this file covers the vendored
assets that are copied into the repository as source or build output.
